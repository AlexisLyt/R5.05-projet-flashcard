## 🛠️ Installation
Run `npm install`
## ▶️ Run the app
Run `npm run dev`
## ⚙️ Environment variables
- `DB_FILE` : the path for the database
- `JWT_SECRET` : a secret key for the token
## 🛢️ Database initialisation :
- **Create database** : `npm run db:push`
- **Seed database** : `npm run seed`
